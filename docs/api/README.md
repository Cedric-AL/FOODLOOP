# FoodLoop API Documentation

The project is still in its early planning and setup stage. At this stage, only the health endpoint is implemented.

## Current API Endpoints

```text
/api/health
```

### GET /api/health

Returns the backend status.

Example response:

```json
{
  "status": "ok",
  "message": "FoodLoop backend is running"
}
```
