# FoodLoop Frontend

This directory contains the initial React + TypeScript + Vite frontend for FoodLoop.

## Purpose

The frontend is currently set up as a clean initial foundation for future interface development. It is not yet implementing the full FoodLoop application.

## Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

## API Configuration

The frontend uses the `VITE_API_BASE_URL` environment variable to connect to the backend API.

Example:

```text
VITE_API_BASE_URL=http://localhost:8080/api
```
